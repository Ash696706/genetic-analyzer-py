# 🧬 Genetic Sequence Analyzer

A beginner-friendly bioinformatics project built with Python and Biopython.

This tool analyzes DNA sequences, performs transcription and translation, and compares a reference sequence with a sample sequence to detect mutations.

## Features

- DNA sequence length
- A, T, G and C nucleotide counts
- GC content calculation
- DNA → mRNA transcription
- mRNA → protein translation
- Stop codon detection
- Reference vs sample sequence comparison
- Mutation position detection
- Mutation summary

## Technologies Used

- Python
- Biopython

## Example

Reference:

ATGGCCATTGTAATGGGCCGCTGAAAGGGTGCCCGATAG

Sample:

ATGGCCATTGTAATGGGCCGCTGAAAGGGTGCCCGATAC

The program compares both sequences and identifies the changed nucleotide.
